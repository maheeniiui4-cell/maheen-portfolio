Maheen Arshad - Portfolio (plain HTML, no install needed)

OPEN IT: double-click index.html. It works offline (fonts load when online).

PUBLISH IT (free): upload this whole folder to Netlify Drop (app.netlify.com/drop),
GitHub Pages, or any web host. Keep all files together in the same folder.

EDIT CONTENT: open script.js in VS Code. Everything you can change is at the top.
 - Project images: put them in the "projects" folder, then set image: 'projects/name.jpg' for that project.
 - Contact form: paste a Formspree URL into FORM_ENDPOINT to get messages by email.
 - CV button: replace Maheen-Arshad-CV.pdf with your latest CV (keep the same name).
